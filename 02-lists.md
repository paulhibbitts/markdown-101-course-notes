# Lists

## Unordered

A list of items in which the order does not explicitly matter. Use `*`, `-`, or `+` to denote a bullet:

```markdown
+ First item
+ Second item
  - A nested item
  - Another nested item
+ Third item
```

Renders to:

+ First item
+ Second item
  - A nested item
  - Another nested item
+ Third item

## Ordered

A list of items in which the order does explicitly matter:

```markdown
1. First step
2. Second step
3. Third step
```

Renders to:

1. First step
2. Second step
3. Third step

**Tip**: if you just use `1.` for every item, Markdown numbers them automatically &ndash; handy when reordering steps later.
