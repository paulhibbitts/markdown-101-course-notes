# Formatting Basics

Let's go over the main elements of Markdown, starting with headings and emphasis.

## Headings

Headings from `h1` through `h6` are constructed with a `#` for each level:

```markdown
# h1 Heading
## h2 Heading
### h3 Heading
```

Renders to:

<h1>h1 Heading</h1>
<h2>h2 Heading</h2>
<h3>h3 Heading</h3>

HTML:

```html
<h1>h1 Heading</h1>
<h2>h2 Heading</h2>
<h3>h3 Heading</h3>
```

## Emphasis

### Bold

For emphasizing a snippet of text with a heavier font-weight.

```markdown
**rendered as bold text**
```

Renders to: **rendered as bold text**

### Italics

For emphasizing a snippet of text with italics.

```markdown
_rendered as italicized text_
```

Renders to: _rendered as italicized text_

### Strikethrough

```markdown
~~Strike through this text.~~
```

Renders to: ~~Strike through this text.~~
